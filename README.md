# Material de Apoio e Sistema Prático

Bem-vindos ao repositório! Este material foi preparado para auxiliar na fixação dos conteúdos abordados na nossa última aula. 

As orientações e arquivos disponibilizados aqui servem tanto para quem esteve presente quanto para quem não pôde comparecer.

---

## Contribuição do Repositório

neste repositório você encontrará:

* **Documentação Teórica:** Arquivo em PDF detalhando o conteúdo e os conceitos explicados durante a aula.
* **Sistema Prático:** Código-fonte do sistema desenvolvido em sala de aula para praticar e testar localmente.
* **Pacote para Download:** Arquivo compactado (`.zip`) contendo todos os recursos necessários para a execução rápida na sua máquina.

---

## Como Utilizar

1. **Faça o download do repositório ou do arquivo `.zip`:**
   * Clique no botão **Code** no topo desta página e selecione **Download ZIP**, ou baixe diretamente o arquivo `.zip` disponibilizado na seção de arquivos.
2. **Extraia os arquivos:**
   * Descompacte o conteúdo em uma pasta de sua preferência no seu computador.
3. **Consulte a documentação:**
   * Abra o arquivo PDF da aula para acompanhar os passos e entender a estrutura do sistema.
4. **Execute e Teste:**
   * Abra o projeto na sua IDE e execute o sistema para realizar os testes práticos.
