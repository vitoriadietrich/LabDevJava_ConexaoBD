1. POO: uma classe, vários objetos

Uma classe é o projeto de um celular; objetos são aparelhos específicos fabricados a partir daquele projeto.

DadosCelular celular01 = new DadosCelular();
celular01.modeloCelular = "Galaxy S24";
celular01.usado = false;
celular01.exibirDadosCelular();
Atributos guardam estado. Métodos executam ações. new cria o objeto. main começa o programa.

O operador usado ? "Usado" : "Novo" decide qual texto imprimir. printf: %s para texto, %.2f para decimal com duas casas, %n para próxima linha.

Exercício: instancie celular02, preencha valores diferentes e imprima os dois.

2. MER: por que não criar uma tabela com 100 colunas?

As imagens da aula reúnem 100 possíveis atributos relacionados a livros, separados por identificação, obra, autoria, publicação, características físicas, formatos digitais, comercialização e estoque.

OBRA (1) -------- (N) EDICAO
EDICAO (1) ------ (N) EXEMPLAR
OBRA (N) ------- (N) AUTOR
           via OBRA_AUTOR
EDITORA (1) ----- (N) EDICAO
A OBRA é o conteúdo; a EDIÇÃO é uma publicação específica; o EXEMPLAR é a cópia física da biblioteca. O número de tombo pertence ao EXEMPLAR.

PK identifica a linha. FK referencia outra tabela. Relações N:N costumam usar tabela de ligação.

Exercício: crie no brModelo OBRA, EDICAO, AUTOR e EXEMPLAR; inclua ao menos duas cardinalidades e defenda sua escolha.

3. Java conversa com MySQL

JDBC é a API para acessar bancos relacionais. O driver MySQL Connector/J traduz essa comunicação para o servidor MySQL.

Java → JDBC → driver → MySQL
Java ← ResultSet ← resultados
String sql = "SELECT id, titulo FROM livro WHERE id = ?";
try (Connection con = Conexao.abrir();
     PreparedStatement ps = con.prepareStatement(sql)) {
  ps.setInt(1, 1);
  try (ResultSet rs = ps.executeQuery()) {
    if (rs.next()) System.out.println(rs.getString("titulo"));
  }
}
PreparedStatement recebe parâmetros seguros. executeQuery() consulta. executeUpdate() insere, altera e exclui.

Antes de rodar: MySQL iniciado, banco criado, usuário/senha configurados, driver JDBC no classpath. Use as instruções do README no ZIP.

4. Swing: a interface que o usuário vê

JFrame é a janela; JPanel organiza; JLabel rotula; JTextField recebe texto; JButton permite interação.

JFrame janela = new JFrame("Cadastro de Livros");
JTextField titulo = new JTextField();
JButton salvar = new JButton("Salvar");
salvar.addActionListener(e -> {
  System.out.println(titulo.getText());
});
Fluxo final: pessoa digita → botão dispara evento → validação → DAO → JDBC → MySQL → feedback na tela.

Exercício: rejeite título vazio e exiba uma mensagem com JOptionPane. Evite consultar bancos lentamente na thread da interface.
