Etapa 01

POO sem mistério

Classe é a receita. Objeto é o bolo pronto. Atributos são características; métodos são ações.

Analogia: fábrica de celulares

Classe: planta de como qualquer celular será descrito. Objeto: o Galaxy S24 específico que você cadastrou. Atributos: modelo, preço, cor, memória. Método: exibir as informações.

class DadosCelular {
    String modeloCelular;
    float precoCelular;

    void exibirDadosCelular() {
        System.out.println(modeloCelular);
    }
}

DadosCelular celular01 = new DadosCelular();
celular01.modeloCelular = "Galaxy S24";
celular01.precoCelular = 4999.90f;
celular01.exibirDadosCelular();

Entenda: new cria um objeto; celular01 é uma variável que referencia esse objeto; . acessa um atributo ou método; f indica um literal float.

Em projetos financeiros, é preferível usar BigDecimal em vez de float, pois números de ponto flutuante podem introduzir imprecisões.

Encapsulamento: protegendo seus dados

public class Livro {
    private String titulo;
    public Livro(String titulo) { this.titulo = titulo; }
    public String getTitulo() { return titulo; }
    public void setTitulo(String titulo) {
        if (titulo == null || titulo.isBlank()) {
            throw new IllegalArgumentException("Título vazio");
        }
        this.titulo = titulo;
    }
}

private impede acesso direto externo; get permite consultar; set permite alterar com validação.

Etapa 04

Banco de dados de bolso

Aqui você simula um CRUD em memória. É um ambiente seguro para errar e aprender sem apagar dados reais.

Tabela LIVRO

IDTítuloAnoAção
Banco simulado: os dados são locais e não estão em um servidor.

Quatro comandos fundamentais

-- CREATE: cria uma tabela
CREATE TABLE livro (
    id_livro INT PRIMARY KEY AUTO_INCREMENT,
    titulo VARCHAR(150) NOT NULL,
    ano INT
);

-- INSERT: insere registros
INSERT INTO livro (titulo, ano)
VALUES ('Java básico', 2026);

-- SELECT: consulta registros
SELECT * FROM livro;

-- UPDATE: altera registros
UPDATE livro SET titulo = 'Java essencial'
WHERE id_livro = 1;

-- DELETE: remove registros
DELETE FROM livro WHERE id_livro = 1;
Cuidado: sem WHERE, um UPDATE ou DELETE pode modificar todas as linhas!

A analogia do restaurante

O Java é o cliente; JDBC é o garçom que leva o pedido; o MySQL é a cozinha que consulta e prepara a resposta. A consulta SQL diz o que você quer.

import java.sql.*;

public class ConsultarLivros {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/biblioteca";
        String usuario = System.getenv("DB_USER");
        String senha = System.getenv("DB_PASSWORD");
        String sql = "SELECT id_livro, titulo FROM livro WHERE ano >= ?";

        try (Connection conexao = DriverManager.getConnection(url, usuario, senha);
             PreparedStatement ps = conexao.prepareStatement(sql)) {
            ps.setInt(1, 2020);
            try (ResultSet resultado = ps.executeQuery()) {
                while (resultado.next()) {
                    System.out.println(resultado.getInt("id_livro")
                        + " - " + resultado.getString("titulo"));
                }
            }
        } catch (SQLException e) {
            System.err.println("Erro no banco: " + e.getMessage());
        }
    }
}

Connection: conexão com o banco. PreparedStatement: comando parametrizado. ResultSet: linhas retornadas. try-with-resources: fecha recursos automaticamente.

O código exige MySQL em execução, banco/tabela criados, driver JDBC disponível no projeto e variáveis de ambiente configuradas. Não coloque senha real em código compartilhado.

Etapa 06

Interface gráfica Swing

Você viu JFrame e JTextField nas imagens da aula. Vamos entender o papel de cada um.

JFrame

A janela principal da aplicação.

JPanel

Organiza componentes dentro da janela.

JTextField

Recebe texto digitado pelo usuário.

Exemplo funcional mínimo

import javax.swing.*;

public class CadastroLivro {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame janela = new JFrame("Cadastro de Livros");
            JTextField titulo = new JTextField(20);
            JButton botao = new JButton("Exibir");
            JPanel painel = new JPanel();
            painel.add(new JLabel("Título:"));
            painel.add(titulo);
            painel.add(botao);
            botao.addActionListener(e ->
                JOptionPane.showMessageDialog(janela, titulo.getText()));
            janela.setContentPane(painel);
            janela.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            janela.pack();
            janela.setLocationRelativeTo(null);
            janela.setVisible(true);
        });
    }
}

addActionListener reage ao clique. SwingUtilities.invokeLater inicializa a interface na thread de eventos do Swing.
